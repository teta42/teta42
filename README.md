## 🧠 Навыки

* 📦 Развёртывание микросервисной архитектуры с использованием Kubernetes (k8s), Ingress, stateful-сервисов и observability-инструментов.
* 🧩 Проектирование архитектур: в последнем проекте самостоятельно разработал полную архитектуру и систему генерации ID по pull-модели на базе PostgreSQL + Redis.
* 🧪 Работа со стеком **Celery + Redis + DRF + PostgreSQL + Docker + MinIO + MeiliSearch** для масштабируемых backend-приложений.
* 📈 Использую стек **Grafana + Loki + Prometheus** для логирования, мониторинга и анализа событий.
